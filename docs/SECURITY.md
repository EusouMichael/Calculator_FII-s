# Segurança e escopo do MVP

Este MVP é uma aplicação local no navegador.

- Os dados da carteira são armazenados no `localStorage` do navegador.
- Não há backend, autenticação, pagamentos ou coleta de dados neste estágio.
- Não há integração com APIs pagas.
- O projeto não deve armazenar credenciais, tokens ou chaves de API no código-fonte.

As informações financeiras exibidas pela aplicação têm finalidade informativa e educacional. Projeções dependem exclusivamente das premissas informadas pelo usuário e não representam garantia ou recomendação de investimento.
